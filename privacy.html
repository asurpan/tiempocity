Política de Privacidad de TIEMPOCITY

Última actualización: Noviembre de 2026

Esta Política de Privacidad describe cómo TIEMPOCITY (desarrollada por asurpan) recopila, utiliza y protege la información del usuario en nuestra aplicación móvil para Android.

1. Información y Datos que Recopilamos

TIEMPOCITY está diseñada primando la privacidad del usuario y la eficiencia energética de su dispositivo:

  • Ubicación de Consulta: La aplicación utiliza el municipio, código postal o barrio seleccionado expresamente por el usuario para solicitar las predicciones meteorológicas a la API de Open-Meteo y AEMET. La aplicación no rastrea ni almacena la posición GPS continua del usuario en segundo plano (0% uso de GPS continuo).
  • Preferencias Locales: Guardamos de forma estrictamente local en el almacenamiento del dispositivo (SharedPreferences) las ciudades favoritas guardadas por el usuario, el historial de caché del tiempo para uso sin conexión y la configuración de avisos (lluvia, polen, alertas AEMET).

2. Permisos del Dispositivo

La aplicación puede solicitar los siguientes permisos de Android exclusivamente para sus funciones principales:

  • Internet (INTERNET / ACCESS_NETWORK_STATE): Necesario para obtener las predicciones en tiempo real de Open-Meteo/AEMET, las imágenes del radar de lluvia y los anuncios de Google AdMob.
  • Notificaciones (POST_NOTIFICATIONS): Solicitado en Android 13+ únicamente para emitir alertas sonoras cuando se detecte probabilidad inminente de lluvia o alertas meteorológicas severas en la ciudad seleccionada.
  • Vibración (VIBRATE): Para generar patrones de vibración distintivos (doble vibración corta para lluvia / triple vibración larga para alertas severas AEMET).

3. Servicios de Terceros y Anuncios (Google AdMob)

TIEMPOCITY utiliza servicios de terceros integrados para el funcionamiento y la monetización de la aplicación:

  • Google AdMob: Muestra banners publicitarios discretos dentro de la app. Google AdMob puede recopilar y utilizar identificadores publicitarios de Android (Advertising ID) y datos anonimizados para la personalización y medición de anuncios de acuerdo con la Política de Privacidad de Google.
  • Open-Meteo / AEMET API: Para la obtención de datos meteorológicos cifrados a través de HTTPS. No se envían datos de identificación personal a estos servidores.

4. Menores de Edad y Privacidad Infantil (COPPA / RGPD)

TIEMPOCITY no recopila a sabiendas datos de identificación personal de niños menores de 13 años. Si cree que un menor ha proporcionado información personal, comuníquese con nosotros para eliminarla de inmediato.

5. Seguridad de los Datos

Utilizamos protocolos estándar de la industria (HTTPS/TLS) para todas las conexiones de red. Las preferencias y la caché de datos permanecen en la memoria privada del dispositivo del usuario y se eliminan automáticamente si se desinstala la aplicación o se borran sus datos desde Ajustes de Android.

6. Cambios en esta Política de Privacidad

Nos reservamos el derecho de actualizar esta Política de Privacidad periódicamente. Cualquier cambio se publicará en esta página web antes de que entre en vigor.

7. Contacto

Si tiene preguntas o dudas sobre esta Política de Privacidad o sobre el tratamiento de datos en TIEMPOCITY, puede ponerse en contacto con el desarrollador a través del perfil de GitHub de asurpan.
